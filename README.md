# AI Resume Builder

An AI-powered Resume Builder built using Flask and the Google Gemini API.

## Features
- AI-generated ATS-friendly resumes
- Professional HTML formatting
- Dynamic Flask backend
- Jinja2 templating
- Responsive UI

## Tech Stack
- Python
- Flask
- HTML
- CSS
- Google Gemini API

## Installation

pip install -r requirements.txt

python app.py
